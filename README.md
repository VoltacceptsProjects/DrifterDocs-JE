# DrifterDocs: JE - The Superior DrifterDocs

DrifterDocs: JE is an innovative text document application focused on secure and customizable text management. Built using Java, it uses a proprietary custom-encoded text document format offering enhanced security and unique functionalities.


## Features

- **Enhanced Security with Encrypted Text Documents:** DrifterDocs uses robust encryption algorithms to protect sensitive information. Each document is encrypted upon saving.

- **Visually Appealing Themes:** Choose from a selection of pre-set themes designed for readability and visual comfort.

- **Multi-Tab Technology for Efficient Workflow:** Manage multiple documents simultaneously with a multi-tab interface.

- **Custom File Type:** DrifterDocs uses its own file format for optimal performance and data handling.

- **Bundled Runtime (3.x+):** JavaFX is bundled directly inside the application jar, so there's nothing extra to install to get up and running.


## Versions

- **Below 3.x:** Requires an external JavaFX Library to be installed and available on the system in order to run.
- **3.x and up:** JavaFX is embedded directly in the jar, so no external JavaFX installation is required. Also switches the native file format from `.drifterdoc` to `.dtx`.
